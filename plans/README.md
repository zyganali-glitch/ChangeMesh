# ChangeMesh Plans

`CHANGEMESH_MASTER_EXECUTION_PLAN.md` is both master roadmap and execution-level plan. Its phases are complete initial child-plan portfolio; agents may not create redundant planning documents before starting.

Create separate child plan only when discovered work cannot fit one micro-task, introduces new subsystem/migration, requires more than three implementation commits, or changes architecture/competition scope. Use root child-plan template and link parent task.
