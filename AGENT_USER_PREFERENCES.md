# ChangeMesh — User and Operator Preferences

## Owner

- Owner: Mehmet Aydoğan
- Primary language: Turkish
- Judge-facing project language: English
- Technical experience: developing with AI agents; prefers copy-paste-ready, explicit guidance
- Budget sensitivity: high; avoid unnecessary recurring cloud cost
- Development environment: Windows desktop, local repository plus GitHub
- Primary development assistant: Google Antigravity Pro
- Reliability preference: agents are not trusted to infer or silently skip steps

## Communication

- Use Turkish with owner unless an English artifact is required.
- Explain unavoidable technical terms briefly.
- Do not provide vague “continue from here” instructions; name exact file, command, expected result, and recovery path.
- Be honest about uncertainty and `NOT_RUN` items.
- Do not ask generic discovery questions; ChangeMesh charter is frozen.
- Ask only one minimal blocking question when truly necessary.

## Development behavior

- Break work into small micro-tasks.
- Keep living plan current in real time.
- Never damage working behavior.
- Prefer reversible and additive changes.
- Synchronize documentation after every task.
- At every closure, scan entire repository for contradiction and drift.
- Do not rely on agent memory outside repository.
- Provide explicit handoff before session ends.

## Product preferences

- Autonomous by default.
- Human-on-the-loop rather than approval-heavy.
- No fake enterprise claims.
- Strong privacy and evidence boundaries.
- Credible independent product after competition, not disposable demo.
- Focus initial product wedge on high-risk schema/API changes.
