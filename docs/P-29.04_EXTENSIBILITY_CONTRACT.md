## 1. Core Extensibility Principles

ChangeMesh provides an open plugin architecture for enterprise teams to add custom change types, infrastructure adapters, simulation scenarios, and organizational policies without modifying the core orchestrator engine.

### Strict Invariant: Monotonic Safety Lock
> **No plugin or extension may weaken core safety, evidence, or authority invariants.**  
> Plugins may only introduce additional constraints, richer evidence artifacts, or specialized domain handlers. Plugins cannot disable secret scanning, downgrade evidence modes, bypass reversibility gates, or execute un-checkpointed state transitions.

## 2. Extension Points & Formal Interfaces

```
                                  ┌───────────────────────────────┐
                                  │   ChangeMesh Core Engine      │
                                  └──────────────┬────────────────┘
                   ┌─────────────────────────────┼─────────────────────────────┐
                   │                             │                             │
        ┌──────────▼──────────┐       ┌──────────▼──────────┐       ┌──────────▼──────────┐
        │  ChangeType Plugin  │       │  Tool/Adapter Plugin│       │    Policy Plugin    │
        │ - parse_request()   │       │ - register_tool()   │       │ - evaluate_rule()   │
        │ - check_reversibility│      │ - capability_passport│     │ - monotonic_restrict│
        │ - build_compensation│      │ - bounded_write_only│       │ - audit_trail_entry │
        └─────────────────────┘       └─────────────────────┘       └─────────────────────┘
```

### A. Change Type Extensions (`IChangeTypeHandler`)
- **Required Methods:**
  - `validate_change_spec(spec: dict) -> bool`
  - `compute_reversibility(spec: dict) -> ReversibilityAssessment`
  - `generate_compensation_steps(spec: dict) -> tuple[CompensationAction, ...]`
- **Constraint:** Must fail closed if reversibility cannot be mathematically proven.

### B. Tool & Infrastructure Adapter Extensions (`IToolAdapter`)
- **Required Metadata:**
  - `tool_id`, `version`, `author`, `canonical_hash`
  - `declared_capability_passport` (must pass `CapabilityPassport` verification)
  - `write_mode` (`READ_ONLY` or `BOUNDED_WRITE_WITH_DRAFT_CEILING`)
- **Constraint:** Direct production mutations or destructive schema drops are forbidden.

### C. Policy Pack Extensions (`IPolicyRule`)
- **Required Evaluation:**
  - `evaluate(change: ChangeRecord, ctx: PolicyContext) -> PolicyResult`
  - `is_stricter_than_base() -> bool` (must be `True`)
- **Constraint:** Custom policy rules cannot override or silence core security and privacy scanners.
