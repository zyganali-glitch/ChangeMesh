### Core Invariants:
1. **Persistence-Before-Event Consistency:** Authoritative state is committed to `SagaStateRepository` with optimistic concurrency version check *before* the corresponding `EventEnvelope` is published to the event bus or recorded in `CausalEventTimeline`. If persistence fails, zero events are emitted and state remains pristine.
2. **Authority Sovereignty:** `PolicyGuardianGate` determines authorization. If `AutonomyClass.BLOCKED`, lifecycle transitions to `ChangeState.BLOCKED` with zero approval cards. If `AutonomyClass.HUMAN_AUTHORITY_REQUIRED`, lifecycle transitions to `ChangeState.AWAITING_AUTHORITY` with a single pending `ApprovalRecord` derived from the authoritative `ApprovalCompressionCard`.
3. **No Downstream Mutations on Non-Authorized States:** Zero execution tasks, zero migration synthesis writes, and zero Release Steward actions occur after `BLOCKED` or `AWAITING_AUTHORITY`.
4. **Execution Evidence Mode Honesty:** Local operations (blast radius analysis, capability lookup, epistemic evaluation, artifact generation, semantic reconciliation) are labeled `FIXTURE` or `SIMULATION` and never `LIVE_WRITE`. ShadowLab always produces `SIMULATION` evidence. `LIVE_WRITE` requires actual credential-backed provider execution with deterministic receipts.
5. **Secret Minimization:** Credentials and secrets are adapter-only. Payloads and intent descriptions are sanitized and secret-scanned before wire message publishing and repository persistence.
6. **Strict Lifecycle Contract Safety:** `ChangeState` enum types are verified with strict `isinstance` checks; arbitrary foreign objects are rejected.

## 6. Forbidden Carry-Over

1. **No UiPath runtime or SDK:** No UiPath Orchestrator, Data Service, Robot, or Action Center dependencies.
2. **No Qwen runtime or unverified memory:** No vector store bypass of epistemic trust validation; memory is never truth by default.
3. **No Codex/GPT runtime or prompt-overrides-fact semantics:** Semantic model judgment cannot rewrite deterministic execution facts or state transitions.
4. **No Routine Human Approvals:** Preserves autonomous-by-default behavior for reversible/rehearsed changes; human authority is reserved strictly for policy-defined high-risk boundaries.
5. **No Caller Fact Overrides:** Untrusted callers cannot inject `force_reversibility_class` to bypass policy rules.

## 7. Intentional Differences from Donor Behavior

1. **Google Cloud Native:** Architecture standardizes on Google ADK agents, Pub/Sub event bus topology, and Firestore operational state repository.
2. **Four-Lane Authority Model:** Complete separation of Organizational Policy, Deterministic Execution Facts, Policy Guardian Enforcement, and Bounded Human Authority Slots.
3. **Approval Compression:** Replaces generic human review forms with structured, machine-verified `ApprovalCompressionCard` packets linking exact locked evidence digests.
4. **Causal Timeline over Wall-Clock:** Causal Kahn DAG traversal enforces dependency ordering even in the presence of distributed clock skew.
