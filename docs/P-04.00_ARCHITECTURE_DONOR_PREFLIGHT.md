# P-04.00 Architecture Donor Preflight Report

## 1. Conflict Resolution

### State Ownership
Firestore Saga (`src/orchestrator/firestore_saga.py`) owns all durable workflow states (derived from D-UIPATH persistent process). There is no conflict with other state mechanisms.

### Evidence Ownership
Evidence Record/Ledger (`src/evidence/evidence_record.py` and `src/evidence/pubsub_timeline.py`) owns deterministic facts and chronologies (derived from D-CCT). Model semantic claims do not overwrite facts.

### Policy Ownership
Policy Guardian (`src/agents/policy_guardian.py`) manages policies and privacy boundaries (derived from D-ZEROKIT privacy preflight). ShadowLab Auth manages destructive targets explicitly. No shared authority.

### Orchestration Ownership
Google ADK Change Orchestrator (`src/agents/change_orchestrator.py`) handles all routing and multi-agent coordination. Provider-specific orchestration is rejected.

### Memory Ownership
Memory Trust Layer (`src/memory/trust_layer.py`) handles cross-session project facts. No unrestricted shared mutable memory is allowed.

### External-Write Ownership
Release Steward (`src/agents/release_steward.py`) owns all external writes, enforcing pipeline writebacks and GitHub limits (derived from D-CONTEXTSEAL).

### Impact Scout Ownership (Blast Radius)
Impact Scout (`src/git/impact_scout.py`) unifies `CS-BLAST-001` (ContextSeal multi-hop dependency paths) and `GL-CONFLICT-001` (GitLab overlapping MR blast radius). It is the canonical target for both, merging repository overlap logic with synthetic metadata graph paths.
