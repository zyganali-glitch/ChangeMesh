### Phase 1: Days 1–30 — VPC Runner Packaging & Private Alpha
- Package stateless customer-hosted runner as production Helm chart and container image.
- Expand database migration coverage beyond PostgreSQL to Google Cloud Spanner and MySQL.
- Deploy in private alpha with 3 selected design partner platform engineering teams.

### Phase 2: Days 31–60 — Enterprise Ecosystem & Compliance
- Ship native integrations for GitHub Enterprise Server and GitLab Self-Managed.
- Implement Infrastructure-as-Code (IaC) change handlers for Terraform and OpenTofu state changes.
- Generate automated compliance reporting packs for SOC 2 Type I and ISO 27001 change management.

### Phase 3: Days 61–90 — Commercial Launch & Developer Tools
- Launch commercial ChangeMesh Cloud (Team & Enterprise tiers).
- Launch public Plugin Marketplace for verified third-party change handlers and policy packs.
- Release VS Code and JetBrains IDE extensions allowing developers to trigger ShadowLab rehearsals from local editors.
