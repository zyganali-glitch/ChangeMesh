## 1. 4-Plane Architecture Topology

To prevent enterprise customer data lock-in and enable deployment across hybrid/private clouds, ChangeMesh defines clean architectural separation across four distinct planes:

```
┌──────────────────────────────────────────────────────────────────┐
│                   1. CONTROL PLANE (Managed Cloud)               │
│  - Multi-tenant Saga Orchestrator & DAG Coordinator             │
│  - Agent Routing, Capability Registry & Passport Verification    │
│  - Approval Compression & Decision Packet Delivery               │
└─────────────────────────────────┬────────────────────────────────┘
                                  │ (gRPC / TLS Event Stream)
┌─────────────────────────────────▼────────────────────────────────┐
│                   2. ADAPTER PLANE (Edge / Hybrid)               │
│  - GitHub / GitLab Bounded VCS Integrations                      │
│  - Database Migration Runners (PostgreSQL, Spanner, BigQuery)    │
│  - Kubernetes & Cloud Run Deployment Actuators                   │
└─────────────────────────────────┬────────────────────────────────┘
                                  │ (Deterministic Policy Rules)
┌─────────────────────────────────▼────────────────────────────────┐
│                   3. POLICY PACK PLANE (Immutable)               │
│  - Organizational Invariants & Reversibility Gates               │
│  - Model Armor & Prompt Injection Defenses                       │
│  - Regulatory Compliance & Audit Rules (SOC2 / ISO27001)         │
└─────────────────────────────────┬────────────────────────────────┘
                                  │ (Zero-Custody Boundary)
┌─────────────────────────────────▼────────────────────────────────┐
│               4. CUSTOMER DATA PLANE (Customer VPC)              │
│  - Customer Databases & Production Schemas                       │
│  - Proprietary Source Code & Migration Checkpoints               │
│  - Customer-Managed Encryption Keys (CMEK)                       │
└──────────────────────────────────────────────────────────────────┘
```

## 2. Zero-Custody Customer Data Guarantees

1. **Zero Raw Customer Data Retention:** The control plane processes only cryptographic fingerprints, change descriptors, and verification digests. Raw customer database records and proprietary schemas never enter control plane storage.
2. **Pluggable Adapters:** Customer infrastructure adapters execute within the customer's VPC as stateless sidecars or runner containers.
3. **Immutable Policy Packs:** Policies are compiled into deterministic bytecode rules evaluated before model invocation.
