# ChangeMesh Collective Memory

## Before a task

Read the four root memory files and `docs/HANDOFF.md`. Extract only information relevant to active plan micro-task.

## After a task

- update lessons for failures, fixes, or reusable warnings;
- update architecture for contracts and boundaries;
- update environment for commands, services, variables, and cloud state;
- update preferences only when owner changes a durable preference;
- update handoff with exact current state.

Do not store secrets, private reasoning, or unverifiable claims.
