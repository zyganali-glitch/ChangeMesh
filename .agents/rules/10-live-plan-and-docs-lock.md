# Live Plan and Documentation Lock

> In Antigravity Customizations, set this workspace rule to **Always On**.

Before editing:

1. inspect repository and Git status;
2. identify one eligible plan micro-task;
3. mark it `IN_PROGRESS`;
4. verify a rollback point.

Before `DONE`:

1. run required tests;
2. record exact evidence;
3. inspect full diff;
4. update every affected document;
5. execute Phase `P-Ω` whole-repository consistency;
6. update handoff;
7. mark task `DONE`.

A code-only completion is forbidden.
